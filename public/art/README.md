# 游戏贴图

共 85 张正式素材。四章延续暗童话手绘桌游质感，各自使用独立怪物与场景设计。

- 4 名角色与 43 种敌人：1024×1024，完整全身、居中、安全留白、真正透明背景；下载 PNG 后转为保留 alpha 的 WebP。
- 27 张场景：1536×1024 JPG，横向构图，无人物。
- 11 张流派卡面：1024×1024 JPG，独立方形画面。
- 全部图片不含文字、水印或边框。

| 章节 | 新怪物 | 背景 | 设计提示词 |
| --- | --- | --- | --- |
| 灰烬古城 | 21 | 7 | `scripts/gen-art.mjs` |
| 熔炉深城 | 10 | 7 | `scripts/chapter-two-art.mjs` |
| 星骸天穹 | 10 | 7 | `scripts/chapter-three-art.txt` |
| 余火终庭 | 2 | 6 | `scripts/chapter-four-art.txt` |

角色与敌人的原始位图均偏向左侧。战斗渲染时只将玩家位图水平镜像，使玩家朝右、敌人朝左；朝向、攻击前冲和受击抖动分层处理。背景的低饱和、虚化和人物轮廓光在 CSS 中实现，源贴图保留原色。

`manifest.json` 只登记已经落盘的图片；缺失素材回退到内置 SVG。下载或替换素材后，在项目根目录运行 `node scripts/gen-art.mjs --manifest-only` 更新清单，无需 API 密钥。

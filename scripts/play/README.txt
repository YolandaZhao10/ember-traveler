余烬旅人 · 电脑试玩包

四章共 65 层：灰烬古城（1–20）→ 熔炉深城（21–40）→ 星骸天穹（41–60）→ 余火终庭（61–65）。
终章只有一条路线：营火 → 精英 → 商店 → 营火 → 最终大 Boss「无昼之主」。
前三章首领提供本角色稀有卡牌与章节遗物三选一，领奖后可继续出发；终章首领击败后直接通关计分。
进入下一章回复 50% 最大生命，保留牌组、遗物、金币与自定义难度。
本版包括 312 张卡牌、208 件遗物、42 个问号事件和 85 张正式美术素材。

第一次运行
1. 安装 Node.js 的 LTS 版本：https://nodejs.org/en/download
2. 完整解压 ZIP，不要直接在压缩包内启动。
3. Windows：双击「play-windows.bat」。
   macOS：双击「play-macos.command」。
4. 浏览器会自动打开 http://127.0.0.1:5199/ 。若未打开，手动复制此地址。
5. 游玩期间保留启动窗口；关闭窗口或按 Ctrl+C 可停止游戏服务。

不需要 npm install、API 密钥或在线账号；安装好 Node.js 后可以断网玩。
请保留所有文件和 site 文件夹的位置。不要直接双击 site/index.html。
若双击无法启动，可在解压目录打开终端，运行：node server.mjs

操作
将攻击牌拖向敌人，沿指向线松手出牌；也可点击选牌后点击敌人。
无需目标的牌拖到战场或再次点击出牌。拖到无效位置、点击空白、右键或 Esc 可取消瞄准。
数字 1–9/0 选牌，Space 打出，E 结束回合，Esc 取消或关闭弹窗；未聚焦其他按钮时 Enter 也可结束回合。
牌堆窗口：数字选牌、Enter 确认、Esc 取消；奖励页：1/2/3 选牌、S 跳过、Enter 继续；地图：WASD/方向键选点、Enter 进入。
右键卡牌看详情；点敌人查看招式。菜单可切换音效与快速动画，并查看遗物图鉴、旅程记录和各角色胜率。
右上角「地图」可查看当前位置和路线，关闭后继续当前进度。
菜单内「快速 SL」（快捷键 R）可重打当前战斗、重选营火敲牌；战胜后只重置领奖与选牌，不用重新打怪。
离开后仍可回退，进入下一节点后更新回退点；奖励内容不重掷。
标题页和局内菜单中的「卡牌图鉴」可查看四名角色的全部卡牌，并对比升级效果。

难度
标题页选择轻松、标准、挑战，或用 50%–200% 滑块自定义各项参数。

存档
存档保存在当前电脑、当前浏览器的本地存储中。
每次使用同一浏览器打开 http://127.0.0.1:5199/，在标题页选择继续旅程。
清除浏览器网站数据会删除存档；隐私窗口不适合长期保存。
每个玩家独立开始，不包含开发者的测试进度。

转发
直接发送整个 ZIP 即可。对方也需要先安装 Node.js LTS。
本地地址仅用于自己的电脑，发给别人不能直接访问你的游戏。

# 怪物数值表（整体强度 ×1.15 之后，未发版）

所有怪物的生命、伤害、格挡统一乘 1.15，对轻松、标准、挑战、自定义都生效，普通怪、精英、首领、讨债人都算。下面的「改前」是乘 1.15 之前的数值。

怎么算：实际生命 = 基础生命 × 生命倍率，实际伤害 = 基础伤害 × 伤害倍率，实际格挡 = 基础格挡 × 格挡倍率，各自四舍五入。减益层数、力量层数、塞牌张数、治疗量不随倍率变化。力量、虚弱、易伤在倍率之后再结算。

档位百分比再乘在下面的标准倍率上。例：挑战难度的普通怪生命 = 标准倍率 × 1.3，伤害和格挡 = 标准倍率 × 1.25。意图达到 125% 时启用部分怪物的复合招式。

# 全部怪物意图一览

- 每个招式列三组数值：**基础效果**是没乘任何倍率的原始值；**标准难度实际**和**挑战难度实际**是乘完楼层倍率、难度倍率和整体强度 1.15 之后玩家实际看到的数值。
- 实际数值写成「a–b」时，a 是这只怪能出现的最早一层的数值，b 是最晚一层的数值；只有一个数表示两层取整后相同。生命同理，基础生命本身是区间时取区间下限配最早层、上限配最晚层。
- 挑战难度 = 生命 ×1.3、伤害和格挡 ×1.25，并且部分招式换成复合招式，表里标了「（复合招式）」。减益层数、力量层数、塞牌张数、治疗量不随倍率变化。力量、虚弱、易伤在这些数值之上再结算。
- 精英最早层按每章第 5 层算。既当普通怪又随精英出场的小怪按它自身的普通倍率列出，随精英出场时还要再乘精英系数。
- 「出招顺序」是把这只怪单独放进战斗、玩家不出牌，用 4 个不同种子各跑 8 回合得到的。4 次完全相同就写「固定」，否则把出现过的顺序都列出来。有队友、被打到半血、被上减益时顺序可能不同；有阶段变化的怪另外列了半血以下的顺序。

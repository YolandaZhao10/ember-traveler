# 全部怪物意图一览

- 数值都是**基础值**，没有乘楼层和难度倍率。实际数值见 [怪物数值表](enemy-values-local.md)。
- 「意图」是怪物头顶显示的类型。「挑战难度」一栏是怪物意图达到 125% 时替换成的复合招式，空着表示和标准相同。
- 「出招顺序」是把这只怪单独放进战斗、玩家不出牌，用 4 个不同种子各跑 8 回合得到的。4 次完全相同就写「固定」，否则把出现过的顺序都列出来。有队友、被打到半血、被上减益时顺序可能不同；有阶段变化的怪另外列了半血以下的顺序。

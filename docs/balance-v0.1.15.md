# v0.1.15 卡牌强度与流派联动

本轮调整 65 张卡牌，覆盖基础输出、防护、发动机、配合牌与终结技。牌池配额不变，零费可重复牌的原有低数值边界不变。普通战斗在地图上的人数、名字、阵容以及辅助阅读标签都隐藏，进场后揭示；精英、首领资料与补给后路保留。

## 设计依据与取舍

参考的是行动效率与构筑资源循环，不照搬另一款游戏的整套数值。初始 3 能量、5 张手牌下，付费铺能力不能长期没有回报；有条件的抽牌、返能与伤害要相互配合。

- 《杀戮尖塔》1 的官方 V2.2 调整同时提高 Blade Dance 的刀刃数、Accuracy 的收益及 Bloodletting 的能量；这说明启动与兑现需要一起考虑。[官方历史补丁](https://store.steampowered.com/news/posts/?appids=646570&enddate=1607901864&feed=steam_community_announcements)
- 2 代的官方角色预告用 Sly 将弃牌变成出牌动作，Regent 用跨回合星星与 Forge 蓄积武器构成不同的资源安排。[Silent 机制预告](https://www.megacrit.com/news/2025-5-15-neowsletter-issue-10/)、[Regent 机制预告](https://www.megacrit.com/news/2025-12-11-neowsletter-issue-17/)。这些是历史设计资料，不把预告数值当作当前 Early Access 的精确平衡基准。

## 八条路线

| 流派 | 核心打法与本次变化 |
| --- | --- |
| 连击 | 先用低费攻击累计次数，再用连环斩、千刃兑现顺序收益。战鼓增加续势，每回合第三张攻击返能一次；多段和重放不算再次出牌。节奏达到两次攻击后返 1 能量，但本牌消耗，避免两张互抽形成无限循环。 |
| 壁垒 | 先防护，再决定是否将格挡用于输出。钢铁意志增加架势，次回合最多保留已有的 6/9 格挡；不能凭空生盾。盾击保留防护，碎盾花掉全部格挡换群体爆发，仍有风险取舍。 |
| 焚烧 | 点燃提高即时伤害和燃烧，余火提高防护；添油翻倍后按燃烧获得有上限的格挡。热浪保留燃烧并附带群体虚弱；引爆提前兑现、花掉持续伤害。 |
| 灰烬 | 灰烬盛宴每回合前两次消耗补手牌并获得防护；火种传递与骨灰提高消耗收益。灰烬再临仍付费、按费用优先回收，本回合先消耗过牌时才补 9/12 格挡，减少“花一回合找回牌却挨打”的空窗。 |
| 血誓 | 血契保留卡牌失血加力，增加每回合首次卡牌失血抽 1/2 张；致死不抽。血刃、殉道提高付血换伤害的效率，猩红护甲与痛觉麻痹支撑风险。 |
| 狂力 | 怒吼提供长期力量；狂暴提供更强的本回合临时力量，配合多段、额外力量倍率。恶魔之心从 3/2 费改为 2 费，升级加强成长，减少开局完全空过。 |
| 回响 | 回响附带即时防护；回声刃与符文爆发提高复制的价值。复制目标和先后顺序仍由玩家安排，能力部署不消耗回响。 |
| 专注 | 专注改为下回合 2/3 蓄能、立即充能。守护符文新增凝神：保留额外蓄力，每回合首张达到 2 层的蓄力牌固定返能 1。迟发刺与环绕碎晶的条件从回响改为自身蓄力，让此路线独立成型。 |

新增能力存入既有状态表与回合标记，沿用 SAVE_VERSION 16，不改变存档结构；刷新保留触发额度，原有能力实例、卡牌 UID 和升级状态不变。效果与描述由同一数据生成。

## 平衡验证与迭代

`audit:builds` 用 8 条路线、4 种场景、每场景 10 种子，前后各 320 场，共 640 场配对。早期为 12 张未升级牌、初始遗物，第 7 层单敌与第 9 层双敌；成熟构筑为 18 张牌（6 初始 + 12 路线牌，路线牌升级）、初始遗物 + 前三章各一件章节遗物 + 4 件常规遗物，分别挑战第 60 与 65 层 Boss。每场满血，生命只计算真实初始值和获得遗物的成长。具体牌组见 `src/test/buildLoadouts.ts`，原始结果见 [JSON](balance-v0.1.15-results.json)。

两边使用相同三步束搜索、束宽三；评估真实回合末与敌方行动，按机制估计能力后续收益，不按牌名加分。不根据搜索过程中未知抽牌的身份安排动作。现有打防基准仍使用原来的五步、束宽六策略。

曾出现的失败及处理：

- 节奏返能出现无能力双牌无限循环，加入消耗后复测通过。
- 血契只保留抽牌导致血誓退化，恢复原有失血加力并叠加有上限补牌。
- 灰烬在第一轮成熟场景 0/20，继续提高消耗攻击收益，并给付费回收增加防护，回收防护先提高到 5/20，进一步加入“本回合消耗过牌”的条件以区别无条件回收防御牌，最终为 3/20。没有改动测试敌人或降低难度来通过测试。

成熟构筑的压力结果（每条路线共 20 场；死亡按失去全部生命计）：

八条路线的配对综合指标均改善；零停滞、零非法状态。护栏优先胜场，再看净损血和剩余敌血；成熟构筑所有压力场景零胜场会失败。并非要求任意牌组都能击败最终 Boss：本次灰烬、狂力在最终 Boss 样本仍偏弱，壁垒、专注更稳，不能由此宣称各路线胜率相等。小样本、满血入场、固定遗物与短搜索也不代表真人胜率或随机整局通关率。

另外保留基础打防配对测试、200 局粗略整局机器人、30 局流程模拟、同角色牌池基础/升级语义去重、零费预算、两张资源牌循环筛查，并新增开启叠加续航能力的循环压力。新增真实出牌测试覆盖三攻返能、消耗补牌上限、致死卖血、格挡支出、回响、蓄力条件、刷新触发边界。

## 复现

```bash
npm run audit:builds -- --seeds 10 --output /tmp/builds.json
# --cards 接受旧 CardDef[] JSON，在相同规则层/策略下覆盖旧卡牌数据；
# --before 接受旧结果并执行配对护栏。旧数据基线提交：9d24912。
npm run audit:builds -- --seeds 10 --cards /tmp/cards-v014.json --output /tmp/builds-before.json
npm run audit:builds -- --seeds 10 --before /tmp/builds-before.json --output /tmp/builds-after.json
npx tsc --noEmit -p tsconfig.app.json
npm test
npm run build
```

# v0.1.11 第三章精英节奏复核

本次只调整第三章三种精英。保留原有生命、开场伤害、主要重击、巨像荆棘和整备窗口，补足弱威胁回合及长期战斗压力。普通敌人、首领、卡牌与遗物数值不变。

## 最终调整

- **月蚀剑侍**：「蚀影印」先进行基础 5 点伤害的轻斩，再施加原有 2 层易伤；「月步」力量由 1 提高到 2。双月斩与落月斩不变，每四回合仍有一次不攻击的月步。
- **星仪守望者**：随从存在时保持原有出招；两只碎镜灵全部倒下后，后续选招改为共鸣、双击、双击循环。已经显示的本回合意图不更改，不增加三敌同时存活时的火力。
- **崩星巨像**：「重聚星骸」先进行基础 6 点伤害的攻击，再回复原有 8 点生命，最后增加 1 力量。开场蓄盾、2 荆棘、24 点落锤和三连击不变；力量从首轮修补之后才开始增长。

以上是基础数值，实战继续应用章节、楼层、难度、力量和减益修正。初次试调曾同时增加剑侍/巨像生命，并让巨像开场获得力量；配对测试显示这会明显扩大原本吃力路线的损失，最终撤回加血并后移巨像力量，集中调整空窗与后续成长。

## 对照方法

运行 `scripts/audit-third-elites.ts`：四角色各两条路线，共八套固定中后期构筑；每套 18 张牌（6 张初始牌、12 张路线牌），其中 8 张路线牌升级。每套包含初始遗物、两件前章遗物、四件常规来源遗物；最大生命仅加上所选遗物实际获得时的生命成长，没有额外赠送力量、能量或格挡。

第三章章内第 5、12、18 层（整局第 45、52、58 层），标准难度，每种组合 20 个固定种子。三种精英加三组普通战对照，每版共 **2,880 场构筑战斗**，另有 360 场九回合不出牌压力诊断。所有比较使用同一组牌、遗物、策略和种子；旧版仅替换敌人定义。单场限制 60 回合/1,000 次动作，前后均为 **0 超时、0 非法动作**。

战斗机器人沿用 `balanceBot.ts` 的启发式选牌与低生命目标集火。平均净失血为创建战斗后的生命减去结束生命，包含治疗抵消；血誓印在创建战斗时扣除的 2 点生命不计入这项净失血。未模拟胜利后的遗物治疗。

## 复现

```bash
export PATH=/opt/homebrew/bin:$PATH
# 旧快照只有类型导入；动态加载时类型会被擦除，不读取/写入当前敌人文件。
git show 5d67b53:src/data/enemies3.ts > /tmp/ember-enemies3-v0110.ts
npx vite-node scripts/audit-third-elites.ts --enemy-module /tmp/ember-enemies3-v0110.ts --seeds 20 --output /tmp/third-elites-before.json
npx vite-node scripts/audit-third-elites.ts --seeds 20 --output /tmp/third-elites-after.json --before /tmp/third-elites-before.json
```

`--enemy-module` 只在该诊断进程的内存中替换 `ENEMIES`，不会改写仓库、浏览器存档或正在运行的游戏。两个 JSON 保存全部构筑、逐路线/楼层数据及压力记录。脚本发现超时或非法动作时非零退出；其余统计用于人工判断，不作为自动通过真人平衡性的结论。

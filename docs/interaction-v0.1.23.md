# v0.1.23 验收记录

本次包含牌堆/奖励/地图快捷键、离手动画、后两章塞牌、挑战复合意图、通关评分及免安装桌面分发。SAVE_VERSION升至19，遭遇固定保存complexIntents；旧档当前战斗和回退点迁移为false，下一场才采用新规则。历史记录升至版本2，兼容版本1；分数保存完整明细，旧记录不推算。

## 牌堆选择

- 检索、回收、置顶和弃牌重放共用数字选牌控件。1–9选择本页前九张，0选择第十张，Enter确认，Esc取消。
- 每页最多10张；超过10张显示翻页按钮，左右方向键也可翻页。换页清除选择，数字无对应候选时不改变选择。
- 键盘选择会将对应卡牌滚动到可见区域。牌上显示数字键帽，窗口显示快捷键说明。
- 弹窗拦截相关按键，避免同时选择战斗手牌、触发原生按钮点击或结束回合。输入文字、组合键、长按重复及忙碌结算期间不触发选择操作。
- 无选择或重放攻击没有有效敌人目标时，Enter不结算。Esc关闭不消耗能量；再次打开不重掷随机候选。

## 离手反馈

- 效果消耗/弃牌快速1100毫秒、普通1400毫秒；卡面保持清晰至动画75%处。主动打出的消耗牌快速360毫秒、普通600毫秒，不额外拖慢已知牌的结算。回响只显示一次实体消耗，随机烧牌仍使用长动画。
- 随机消耗/弃置保留实际牌名与卡面；每批最多4张，连续批次错开，结算忙碌时间与展示时间一致。
- 系统减少动态效果设置仍使用淡出并保留牌名。正常出牌进入弃牌堆和回合末整手弃牌不新增提示。

- `npx tsc --noEmit -p tsconfig.app.json`、`npm test`、`npm run build`。
- 77个测试文件、1471项测试通过；离手时序用例检查长短动画、多牌批次及先存档后动画。
- 独立sessionStorage测试页，未覆盖玩家存档。桌面1280×720、窄屏390×844验收，无浏览器错误或警告。
- 12张候选：0选择第十张并滚动到可见处；右键翻页清空选择；第二页无效数字不选择；1选择第十一张，Enter只回收该原牌、仅扣一次费用，仍在玩家回合。
- 随机三选一：未选择时Enter不扣费，2高亮第二张，Esc取消，再次打开候选相同；3、Enter仅移动第三张，回响不重复移动。
- 弃牌重放：2选择单体攻击，无目标时Enter不结算；指定第二名敌人再按Enter，费用和出牌次数正确，仅指定敌人受伤。
- 快速模式实测焚书显示“随机消耗 · 打击”及来源消耗牌，停战烟显示“随机弃置 · 打击”，实际CSS动画均为1.1秒；菜单切换普通模式后实测弃牌为1.4秒。
- 窄屏可翻页、看到选中卡牌及确认/取消按钮。测试完成后恢复默认视口并移除临时页面。

## 桌面分发

官方Electron 45.2.3运行时，使用@electron/packager 20.3.0构建；提供Windows x64、macOS arm64与x64。游戏使用固定的本地ember协议加载生产资源，不开监听端口，不需要联网；渲染进程启用沙箱和上下文隔离，不开放Node.js、外部导航、新窗口或设备权限。存档放在系统用户目录下固定的EmberTraveler目录，更新解压路径不改变存档。

桌面包与浏览器原存档各自独立，不自动导入。压缩包只装入生产构建与桌面启动程序，不携带开发密钥、临时页面、测试存档或开发依赖。未做开发者证书签名/公证；首次启动可能有系统确认提示。

Mac Apple Silicon版已在本机启动，人物/场景贴图与中文界面正常，实际开始旅程、进入地图和战斗，并用数字1和Space打出防御，能量3→2、获得5格挡。Windows和Intel Mac版仅完成交叉构建、应用资源与文件格式检查，没有在对应系统实机运行。

## 奖励、地图、评分与独立画风

- 奖励1/2/3选择，S跳过，Enter继续；有必选章节遗物时不能提前离开。主地图WASD/方向键比较，Enter进入可达节点；未来节点、预览地图、绘画和弹窗不会误触发移动。浏览器验证选择不重复领取、金币自动拾取和预览只读。
- 最终通关基础3000分，完成层数每层20分、精英每名50分（最多20名）；初始/普通/罕见/稀有遗物分别10/25/50/75分，问号/商店75分，章节100分，重复ID不重复计分。剩余金币每枚1分，最多1000；累计出牌（含回响）每张2分，最多500。
- 构筑分取最高20张：初始10、普通25、罕见40、稀有65，升级加15；每张诅咒扣40，构筑最低0分。这是稀有度和升级投入指标，不是精确战力评价，也不鼓励无限扩牌。总分乘以难度系数：四项敌方生命/意图平均比例，除以至少1的金币/两项稀有度平均倾向；系数限0.25–2。用时和伤害不计分。
- 通关分数随完整明细保存到旅程记录，SL覆盖同局记录，旧记录不补算。浏览器验证最终页展开明细、菜单历史列表和详情一致；无控制台错误。
- 人物、怪物、场景背景分别选择现有或简易；卡牌独立选择正常、简单、繁复。旧整套偏好迁移为对应四项，不改进度或随机流。切换立即生效、刷新保留。
- 繁复卡面增加金属双边、角纹、稀有度宝石和符文底图，按回收、治疗、加费、抽牌、燃烬、攻击、防御等实际效果选择实体纹章，保留原牌图标作小印记；正常与简单画风仍可选。后三章简易敌人补齐体型轮廓，避免回退为占位圆形。

## 困难复合意图

只对挑战预设或对应意图设置达到125%的新遭遇启用，普通/精英与首领各自读取设置。15个复合招式及最终首领的困难开场使用完整替代行动，预告、详情、实际结算读取同一组定义，不改变出招顺序。头顶显示格挡、强化和塞牌的附加效果。

- 第一章：墓灰傀儡抖灰带轻击、重击带小格挡；灰烬教徒首轮仪式带轻击。
- 第二章：烟尘先知烟幕带轻击；添火侍从扬灰时自增力量；锁链卫兵收链带轻击、拖拽斩带小格挡。
- 第三章：风页抄写者塞眩晕时轻击；星轨卫士贯星带小格挡；星仪守望者共鸣带轻击；坠星司辰帷幕带轻击，屏障保留不攻击窗口。
- 终章：终庭执卫封庭敕令也攻击，断路重斩追加小格挡；无昼之主横扫追加格挡，终夜壁垒强化2力量并塞3张眩晕，仍不直接攻击。困难首轮重扫基础伤害24→40，只出现一次，提前预告；标准仍为24。没有加入穿透。

使用与塞牌测试相同的4角色8构筑、9组后期遭遇、8种子，在挑战难度下对比关闭/开启复合招式，各576场。未见非法状态或停滞；固定构筑总胜场402→389。用户将困难最终Boss目标进一步调整为约10%，该场允许下降20个百分点，其余遭遇保留15个百分点护栏。最终Boss胜率下降18.75个百分点、额外生命损失增加12.64个百分点；其他遭遇仍在原护栏内。

最终Boss初步调到18.75%后，按新目标继续比较：只继续叠力会集中压垮回响构筑；试验穿透产生0/64胜场，已撤回。最终使用每次壁垒+2力量、一次性开场基础伤害40。原8种子为6/64（9.375%）；额外未用于调参的8种子也是6/64，合计12/128（9.375%），无停滞或非法状态。标准难度未改攻击和强化数值。机器人结果只代表这些满血成熟构筑，不代表真人或整局通关率；当前获胜样本集中在学者（原组回响1、专注5，新组专注6），不能据此声称四角色通关能力已经均衡。

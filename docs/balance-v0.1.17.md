# v0.1.17 卡牌相似性与平衡复核

覆盖282张卡、557个基础/升级形态，修改17张。角色、稀有度、ID与卡池配额不变。存档仍为16：没有新增存档结构，长明额度使用已有的 turnFlags；已经部署的旧能力保留原效果，新出牌使用新定义。

## 重复性检查

旧检查只比较同一角色可获得的奖励牌，精确检查也把保留/消耗当成效果差异。扩大到全部角色后发现16组近似设计；忽略生命周期后，还发现埋灰短刃基础版与回旋踢升级版攻击、抽牌完全相同。前版未发现普通升级与稀有牌完全同效，本次继续做所有基础/升级交叉比较。

最终：完整机制重复0组；忽略生命周期的奖励效果完全重复0组；忽略数值、费用、段数、单群体、保留/消耗和角色的奖励设计重复0组。初始打击/防御等模板不参加去数值审查，但所有卡都参加完整机制审查。运行 `npm run audit:card-similarity` 可复跑；严格检查也进入 `npm test`。

人工另查资源爆发、定向/随机回收、能力组合、蓄力与治疗等同类牌。基础操作可以服务于不同构筑：盾击保留格挡而碎盾消耗格挡；火线蔓延复制已有燃烧而燎原施加固定燃烧；共鸣/博学分别提供单一持续资源，活页秘典用较高启动费用同时提供二者。保留有资源、时机或启动代价区别的组合，不把相似性检查当成玩法质量的自动证明。

## 平衡对照

基线为088648e（v0.1.16）。旧、新牌使用相同引擎、规划器、种子与支持牌规则，标准难度。规划深度3、束宽3，不预知未抽出的牌，每场50回合/500行动上限。新状态长明的前瞻估值为4；旧版无此状态，因此不改变旧牌评估。

共10,528场正式前后对照（不含撤回试改），无停滞或非法状态。另覆盖557形态×4资源情景，共2,228个实际结算探针。

试改与撤回：更高的骨灰裸伤使灰烬成型组配对得分下降0.800，已撤回，保留18/25裸伤及有上限成长。首版长明失去防御后退化，改为首次消费时防护并抽牌，仍只有一次额度。余烬疗愈转型净化后降至零费并保留消耗，避免挤占当前回合防御。没有降低既有测试阈值。

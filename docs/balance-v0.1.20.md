# v0.1.20：角色资源、能力分工与终章压力

## 玩法改动

四角色各加两张罕见专属牌，均为 0 费、消耗，升级仍消耗。转换需要真实资源；不能靠回响或重放重复领取已经兑换的本回合计数。

| 角色 | 抽牌 | 能量 |
| --- | --- | --- |
| 旅人 | 战途补给：本回合每打出 1 张攻击兑换抽 1，最多 2/3 | 卸甲疾行：每消耗 10 格挡获得 1，最多 2/3 |
| 拾灰者 | 灰中索引：本回合每消耗 1 张牌兑换抽 1，最多 3/4；自身最后消耗 | 借火鼓风：每消耗目标 4 层燃烧获得 1，最多 2/3 |
| 血誓者 | 回脉忆战：每实际治疗 2 生命兑换抽 1，最多 3/4；过量治疗无效 | 借怒：每消耗 2 点现有临时力量获得 1，最多 2/3；不扣永久力量 |
| 灰语学者 | 回声批注：每完成一次回响或镜像兑换抽 1，最多 3/4 | 释能演算：每消耗 2 层手牌蓄力获得 1，最多 2/3，从最低蓄力开始 |

普通、精英及未指定牌名的事件奖励，单槽先选稀有度，再按 25% 通用、75% 角色专属选池。此概率不是每组三张恰好含多少张通用；前三章 Boss 仍只给本角色稀有牌。新增通用普通「燃烬借力」「烬中翻阅」，支付余烬并消耗自身换能量、抽牌。

重放选中的实体牌结算期间移出弃牌堆，结束后遵循原卡的弃置/消耗规则，实体只处理一次。回响、镜像的每次效果重新检查余烬代价；不足时跳过该次。再生在回合末治疗后衰减 1 层。誓血回生、涅槃之息、许愿余烬与赤玉神像补偿再生层数。

## 能力牌分工

14 张能力更换核心触发，避免仅改数字或回合时点。所有自动描述来自同一效果数据。

| 能力 | 核心用途 |
| --- | --- |
| 先锋誓言 | 攻击/技能交替配对，每回合前两对格挡与抽牌 |
| 漫长守望 | 留下能量，回合末格挡、下回合多抽 |
| 火葬 | 2 费立即群体燃烧 14/21，敌人死亡时传播剩余燃烧，至少 4/6 |
| 不息炉膛 | 首张一次支付至少 3 余烬的牌触发群体燃烧 |
| 灰烬储备 | 1 费即时格挡 8/12，生效后每回合第二次消耗时起甲并回收最高费消耗牌 |
| 血色盟约 | 1 费，卡牌累计失血至少 4 后有限治疗和 1 能量，每回合一次 |
| 猩红护甲 | 1 费即时格挡 12/17，将实际治疗变为格挡，每回合上限 12/18 |
| 战意化身 | 卡牌获得临时力量时起甲，每回合上限 12/18 |
| 铁血 | 第二次攻击把最多 2/3 点现有临时力量留下，不凭空造力量 |
| 寂静序曲 | 打出已蓄力至少两层的牌，给下一张牌回响，每回合一次 |
| 活页秘典 | 每回合完成第二次额外回响/镜像后抽牌并加费 |
| 星界庇护 | 回合末支付手牌一层蓄力，换格挡和荆棘 |
| 火星冠冕 | 每回合首次实际支付余烬，获得有限临时力量 |
| 篝火避难所 | 回合末支付 3 余烬维持格挡 |

血色守望保留「失血起甲」，涵盖敌方伤害、反伤与卡牌失血；与治疗起甲的猩红护甲分工不同。所有实际治疗统一计数；满血、死亡与过量治疗不能刷甲或抽牌。

## 怪物与迭代

第一章部分普通怪约加 6% 生命、首领约加 8%；第二章多数普通怪约加 8%、多数精英约加 5%；第三章多数普通怪约加 12%、两只单体精英约加 5%。第三章碎镜灵、抄写者、猎犬、剑侍的部分强化回合先轻攻击再强化，仍显示对应意图。

标准难度第 62 层终庭执卫生命 550；第 65 层无昼之主生命 1220，每回合最多失去 305 生命。首领第二阶段重扫和坠夜增强、觉醒附带弱攻击，纯整备回合保留。

测试暴露的过强点已回调：第二章炉窑监工、第二章首领、第三章碎镜灵和星仪守望者组合、第三章首领不再额外堆血；碎镜灵强化附带的基础攻击从 2 降到 1。终章精英曾试过 190–200 基础生命，终章首领曾试过 440，最终分别定为 185、430，避免把已有胜场的流派直接压成零胜。

能力的部署也做过调整：灰烬储备增加即时格挡并减至 1 费。火葬原方案的即时燃烧 10/15 在 50 种子焚烧构筑中退化，12/18 仍未通过配对评分，最终 14/21 通过；费用保持 2，传播职责保留。

最终验证：TypeScript 检查、69 个文件共 1,358 项测试、生产构建全部通过。试玩包含全部 94 张美术资源；SHA-256：`8c8dfcd4d3bfbe36aa8d9fea22411dc89098f148c825df59bc292c6dc7807811`。

- 293 张卡、579 个基础/升级版本交叉比较：完整机制重复、奖励效果重复、忽略数字等后的核心设计重复、能力核心完全包含，均为 0。机器检查不等于穷尽所有语义近似。
- 14 张能力、基础/升级、单体/群体/精英、8 种子，新旧配对共 1,344 场，无非法状态、停滞或超过严重退化护栏的项目。
- 四角色八流派的章节遭遇对照共 19,584 场，新版胜 9,600/9,792、对照 9,592/9,792；与 v0.1.19 怪物数值对照的后两章 5,376 场，新版胜 2,559/2,688、对照 2,573/2,688。逐场景、逐章逐流派及后两章 Boss 的护栏均通过。两组测试有重叠，不能相加当独立样本。
- 固定构筑 10 种子、4 场景共 320 场；同策略旧能力定义对照，八流派均未触发配对退化护栏。焚烧额外扩大到 50 种子：第三章 Boss 33/50 对 32/50，终章 Boss 2/50 对 1/50。
- 新资源牌与等张数防御牌对照，各 320 场；资源牌均有被实际打出，无非法或停滞。配套血誓构筑第三章 Boss 10/10、终章 2/10；灰烬与狂力构筑第三章都只有 1/10、终章 0/10，仍是后续真人试玩重点。转换牌提供选择，并非每套牌无条件优于防御。
- 16,770 对资源牌枚举，最多 11 次操作；四角色及一组不能自然获得的跨角色极端组合，基础/升级、24 种子、12 回合压力测试，没有达到循环护栏或出现非法状态。有限范围检查不能证明任意多牌组合绝无无限循环。
- 完整测试中的简单整局机器人多数路线仍是 0/20，学者专注 1/20；它只作粗评，不作为「真人胜率」或「所有流派已平衡」的证据。固定构筑测试检验战斗收益与改动退化，不模拟完整选牌决策。
- 浏览器实际检查重放选择、实体消耗、实际治疗抽牌、临时力量换能量、刷新恢复、图鉴详情返回和长描述；286 张非诅咒基础/升级卡的小尺寸描述无越界。终章显示 1220 生命和 305 承伤上限。验收页使用独立 sessionStorage，未覆盖玩家存档。

新增数值放在现有状态与回合计数字典内，存档版本保持 18。战斗中的老存档保留已生成敌人生命，新遭遇采用新数值。

## 新怪物美术

用户指定的网页版生成了前三章各 3 张新怪物图，逐张检查 1024×1024 RGBA、真实透明、安全留白、左向姿态，再无损转 WebP。隙星枪客首版偏小，单独重新生成较直立构图。三章都在实际三敌战场检查；美术总数 94，覆盖全部 52 种敌人。

源提示与修正提示：`scripts/extra-enemies-art.txt`。正式文件：`public/art/enemy_ash_crossbow.webp` 等 9 张，清单在 `public/art/manifest.json`。无需新增运行时依赖。

```sh
npx tsc --noEmit -p tsconfig.app.json
npm test
npm run build
npm run audit:card-similarity -- --output docs/card-similarity-v0.1.20.json
npm run audit:sustain
npm run audit:power-builds -- --baseline docs/cards-before-v0.1.20.json
npm run audit:builds -- --cards docs/cards-before-v0.1.20.json --output docs/builds-control-v0.1.20.json
npm run audit:builds -- --before docs/builds-control-v0.1.20.json --output docs/builds-v0.1.20.json
npm run audit:builds -- --resources control --synergy yes --output docs/resources-control-v0.1.20.json
npm run audit:builds -- --resources candidate --synergy yes --output docs/resources-v0.1.20.json
npm run audit:builds -- --route cinder --seeds 50 --cards docs/cards-before-v0.1.20.json --output docs/cinder-control-v0.1.20.json
npm run audit:builds -- --route cinder --seeds 50 --before docs/cinder-control-v0.1.20.json --output docs/cinder-v0.1.20.json
npm run audit:opening-pressure -- --all-chapters --stats-baseline docs/enemies-before-role-v0.1.20.json --seeds 8 --output docs/role-enemies-v0.1.20.json
npm run audit:opening-pressure -- --late-game --stats-baseline docs/enemies-v0.1.19.json --seeds 8 --output docs/late-enemies-v0.1.20.json
node scripts/package-game.mjs
```

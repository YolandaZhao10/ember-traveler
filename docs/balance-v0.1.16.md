# v0.1.16：全卡稀有度审查与精英预览

审查282张卡牌、557个基础/升级形态（诅咒没有升级），调整38张：普通1张、罕见10张、稀有27张。五个可获得牌池仍各为20普通、18罕见、15稀有，没有通过更换稀有度标签规避数值问题。完整清单与逐项结论见[全卡表](card-rarity-v0.1.16.md)，可复核的逐场汇总见[测试数据](balance-v0.1.16-results.json)。

## 本轮判断与调整

普通牌提供基础效率和少量条件收益；罕见牌应以更好效率、控制或联动弥补使用成本；稀有牌应在爆发、持续成长或资源转换上有明确的构筑价值。比较同费用、同准备资源与升级状态；不把高稀有度理解成所有场景下都更优。能力打出即移出牌堆，保留占用手牌，消耗会花掉未来轮转，永久再生不能当作逐层衰减来估价。

- 旅人：长夜终灯、环刃补足连击兑现；先锋誓言增强升级收益；不动阵地强化反击；铁壁回敬按双倍格挡转伤，保留两费、单体、虚弱和不消耗格挡的取舍。
- 拾灰者：积灰护甲更易启动，灰烬储备提高消耗触发伤害；火线蔓延、送葬火炬、窒息余火补足稀有燃烧收益；白热提高转换上限并返还一能量，但仍清除燃烧且消耗；灰中复苏提高治疗以补偿随机消耗手牌的代价。
- 血誓者：旧伤回响可以保留等候窗口；血色守望、盟约加强失血收益；乱锤、誓约裁决、战意化身提升对应流派价值；撼地和基础铁血降为两费。
- 学者：和声盾、鸣钟、寂静观测加强各自防护/控制用途；寂静序曲更早启动；破碎合唱、恒久护印、归一、星界庇护补足稀有收益。
- 通用：灰烬之刃补偿余烬消耗；稀有治疗、火星冠冕、篝火避难所、百灯夜行、暮火裁决更值得付费；扫火与两张罕见补给牌修正偏低效率。

重复机制、普通升级与稀有基础完全同效、零费可重复资源循环仍由既有测试阻止。所有描述继续从效果生成。本轮不新增存档字段。

## 失败试改与复测

献灰曾试改为零费；固定后期灰烬构筑的配对评分下降0.413，未采用。随后测试减少手牌消耗并给予下回合蓄能，下降0.848，也撤回。最终保留原卡，不以“更便宜”推断一定更强。开篇和弦经生命周期核对，属于一次性能力部署，保留原费用。

全卡精英探针最初将战斗上限设为30回合，葬灰帷幕的两种形态在旧、新数据下均会因大量消耗与防护超时。统一扩展到50回合、500次操作后，双方都正常结束；没有把超时记作胜利。其余已在30回合内结束的对照无需重跑。所有最终报告按同一有效上限解释。

精英探针只是在固定12张牌组内用两张候选牌测试；其余六张支持牌按流派固定，四张为打击/防御，只有候选位随基础/升级切换。普通、精英场景与前后版本采用同一规划器，不对特定牌名加分；搜索不读取未知牌序。上表的胜场不是整局胜率，也不是玩家胜率。全量报告保留负面样本：积灰护甲在首组种子少一胜但平均损血更少；第二组种子没有改动牌出现胜场下降。白热等资源转换牌在固定支持组中也未必有即时收益。

现有200局粗略整局机器人仍是0通关、0停滞，无法据此宣称四章或八流派已经达到真人平衡。该策略不善于控制消耗牌、搭配选牌和长线资源，后期灰烬/狂力仍是需要持续观察的路线。本轮没有放宽回归门槛或调整机器人来制造胜率。

复跑：

```sh
npm run audit:card-rarity -- --output /tmp/cards-normal.json
npm run audit:card-rarity -- --elite --seeds 4 --output /tmp/cards-elite.json
npm run audit:card-rarity -- --elite --seeds 4 --seed-offset 4 --only iron_rebuke,white_hot --output /tmp/cards-holdout.json
npm run audit:builds -- --output /tmp/builds.json
npx tsc --noEmit -p tsconfig.app.json
npm test
npm run build
```

`--cards` 可传入CardDef数组，使用历史卡表复跑同一策略；基线提交是6886e6f。`--only`用于定向复测，`--probes-only`仅执行全量效果探针。完整前后对照和第二组种子共15,056场（不计开发中的失败实验和既有打防回归）。

## 界面验收

普通与精英在节点角标、辅助标签、选中详情和只读地图中都不显示敌名、人数或阵容；首领仍可查看资料。选择精英仍可比较收获、补给距离和后路精英场数，确认进场后正常显示实际敌人。1366×768与390×844已检查；窄屏没有新增横向溢出。

卡牌图鉴新增独立“诅咒牌”分类，7张诅咒不再混入全部角色、通用或包含通用的角色分类。切换分类重置搜索及类型/稀有度筛选；诅咒页仅保留搜索和详情，不提供无意义的升级开关。验证了通用56张、独立诅咒7张、带筛选切换、悔恨详情与返回。

实际打出铁壁回敬：13格挡转换32伤害，格挡保留、扣2能量，刷新仍恢复同一结果；较长卡面说明在实战与详情正常显示。浏览器测试使用独立会话存储，没有改写玩家存档。

# v0.1.12 零费卡牌收益与消耗复核

检查全部基础版和升级版：共有 **48 张**卡牌至少一个版本为 0 费，其中基础版 42 张、升级版 48 张。此次调整其中 14 张：5 张限制消耗，9 张降低可重复获得的数值。其余 30 张非能力牌已经消耗；4 张升级后零费的能力牌沿用打出后移出循环的规则。

保持零费牌的连击、失血、燃烧、回响与保留用途。消耗牌仍可通过明确的消耗区回收效果再次获得；这里的限制是不能自然洗回牌堆反复免费使用，不是禁止已有的回收机制。

## 增加或保留消耗限制

| 卡牌 | 调整 |
| --- | --- |
| 焚书 | 基础版、升级版均增加消耗；消耗其他手牌换能量和升级抽牌的数值保留。 |
| 血祭 | 基础版、升级版均增加消耗；失去 3 生命、获得 1 能量及抽 2/3 张牌保留。 |
| 震慑 | 基础版仍消耗；升级版不再移除消耗，改为对所有敌人施加 2 层虚弱，保留升级价值。 |
| 折页护符 | 基础版、升级版均增加消耗；保留、蓄力及有回响时的蓄能效果保留。 |
| 掩灯 | 基础版、升级版均增加消耗；原有格挡和满足余烬条件时的群体虚弱保留。 |

## 复现

旧版使用提交 `4fbdc67`。可导出一个不含 `.git` 的临时快照，复用本机已安装的依赖，在独立目录中运行，不切换当前工作区：

```bash
export PATH=/opt/homebrew/bin:$PATH
game_source="$PWD"
zero_card_baseline=$(mktemp -d /tmp/ember-v0111.XXXXXX)
git archive 4fbdc67 | tar -x -C "$zero_card_baseline"
ln -s "$game_source/node_modules" "$zero_card_baseline/node_modules"
cd "$zero_card_baseline"
npx vitest run src/test/balance.test.ts > /tmp/zero-cards-balance-before.log
npm run audit:third-elites -- --seeds 20 --output /tmp/zero-cards-third-before.json
cd "$game_source"
npx vitest run src/test/balance.test.ts > /tmp/zero-cards-balance-after.log
npm run audit:third-elites -- --seeds 20 --output /tmp/zero-cards-third-after.json --before /tmp/zero-cards-third-before.json
```

两份 JSON 包含固定牌组、逐楼层/路线结果和原始压力统计；日志保留整局平均层数、停滞与主要死亡遭遇。所有诊断只在内存中运行，不读取或修改玩家浏览器存档。

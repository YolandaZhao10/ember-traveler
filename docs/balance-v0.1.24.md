# v0.1.24 四角色终局平衡与条件牌差异化

最终验收按玩家最新要求：**四个角色分别不超过 5% 的困难最终 Boss 机器人胜率，不设最低线**。胜率只用于固定构筑测试，不向玩家显示掉落或胜率参数。

## 测试口径与结果

使用挑战预设（生命130%、意图125%）和第65层无昼之主；每场满血。每个角色各两条流派，每条流派同时保留旧构筑 legacy 和加入角色资源牌的 synergy 构筑，等权统计。每副18张牌，6张初始牌、12张已升级支持牌；初始遗物加3件章节与4件常规来源遗物，生命增长按实际遗物计算。构筑在数值修改前固定，完整牌表、遗物、逐种子结果均在 JSON 中。

## 规则和卡牌

- 最终首领基础生命仍430，第65层标准1220、挑战1586，每玩家回合最多失去25%生命（挑战397）。困难开场基础伤害40→24（实际63），每场只使用一次；困难永夜横扫22→24，终夜壁垒每轮力量2→3。把压力从首轮淘汰转到持续循环。觉醒清除其他减益、保留一半燃烧（向上取整），让焚烧仍有持续收益；意图和详情明确提示。
- 连击：续势在本回合第3次攻击时，除能量外每层获得8格挡，回响计次但第6次攻击不重复触发。千刃在本回合已有2次攻击时获得16/24格挡；先锋誓言护甲4/6→8/12。铁壁金属化3/4→4/5。
- 拾灰者：添油燃烧转格挡倍率1→2、上限12/18→18/24；灰烬盛宴每次消耗起甲4/6→8/12；火种传递12/18；灰烬再临条件格挡12/18。保留燃烧与消耗两条路线不同的资源要求。
- 血誓者：吸血撕咬单次实际治疗上限8/16；痛觉麻痹条件格挡8/12；血色守望6/9；升级血契2层血怒。猩红护甲每点实际治疗转2格挡、每回合上限20/30；战意化身每点临时力量转3格挡、上限20/30。恶魔之心入场格挡12/18、每回合力量3/5、金属化5/8。过量治疗不产盾、不允许死亡后吸血复活、回收仍移动同一实体。
- 学者：回声刃伤害8/11→7/10；蓄势之刃10/14→9/13。回声批注单次抽牌上限3/4→2/3；释能演算每3层蓄力换1能量（原2层），上限2/3且仍消耗。蓄力统一最多10层，保留成长、立即充能、遗物、预览、兑换和读档都遵守该上限，旧存档不能保留隐藏的超额蓄力。回响计次和角色牌堆循环仍保留。
- 荆棘甲基础/升级均新增消耗，回响不复制卡牌实体，洗牌不能直接重复叠加。盾缘6/9伤害、有格挡时获得2/3临时荆棘，下回合开始全部移除；与永久荆棘相加但不消除永久荆棘。

斜线均为基础/升级值。存档字段结构不变，版本仍为19；旧战斗生命不强制重算，旧蓄力按新上限归一化，快速SL快照同样处理。

## 修复近似和完全下位卡

旧检查只比较完整效果结构，漏掉了“有条件的小收益被无条件牌全面覆盖”。这次补充保守的收益上界检查：条件全满足后，仍被同费用无条件牌全面覆盖则失败，并加入旧盾缘定义的反例测试，避免检查永远返回空列表。

- 盾缘侧重本轮反伤，交锋仍提供即时格挡，不再是同费弱化版。
- 守夜获得6/9格挡；余烬≥3时，下回合额外保留最多8/12点已有格挡，随后移除准备。不能凭空造盾，不替代永久固守。
- 扇火斩8/11伤害；余烬≥2时真实花2余烬，随机弃1张、抽2/3张；回响再次结算也要支付，不再是回旋踢的条件下位。

303张牌、598种基础/升级形态通过完整效果、普通升级与稀有基础、近似设计、能力覆盖和条件收益覆盖检查。成长、复杂资源与多段收益不能只相加比较，仍需要人工判断；不能把自动结果当作全卡池绝无相似设计的证明。

## 怪物与营火

- 双生哨卫护卫、余烬虫蠕动：起甲并施加1回合脆弱。
- 灰烬税吏账本壁垒：起甲、净化并施加2回合脆弱。
- 熔渣巨像聚渣：起甲并施加2回合易伤，留一个玩家回合应对，下一回合塌炉；塌炉基础伤害20→16，易伤时为24，避免直接把原重击再放大50%。
- 风页抄写者合诵：轻击后施加1回合脆弱。困难添火侍从扬灰：塞冷灰并施加1回合脆弱。
- 上述整备改掉反复叠力量。多段怪、群体援助和压力釜“加压后释放”的力量特色保留；双生哨卫的同伴死亡暴怒仍是一次触发。
- 新增“防御＋削弱”意图，明确显示易伤/脆弱层数。修复最后1回合易伤将在玩家回合末到期时的伤害高报，意图和详情共用计算。
- 选择现有场景背景时，营火休息/锻造/精简增加专属插画、暖光、边框；简易背景保持简洁。1280×720一屏显示，锻造仍先预览再确认，已使用选项仍正确禁用。

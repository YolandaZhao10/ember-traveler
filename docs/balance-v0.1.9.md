# v0.1.9 遗物平衡与差异化

本轮检查全部 208 件遗物，调整 83 件，其中常规/角色专属 37 件、前三章奖励 27 件、问号/商店专属 19 件。调整包括削弱过高收益及重做重复用途，并非把所有遗物同比例削弱。遗物数量、ID、稀有度配额和获取渠道不变。终章已停发的 9 件纪念遗物保留原定义，兼容旧档；当前可获得内容为 199 件。

## 主要取舍

- 收敛低门槛免费资源：燧石首攻加伤 4→3，水壶战后治疗 6→4，余灰灵种每回合首次消耗治疗 2→1；透镜改为偶数回合有保留牌时回能。余火香炉空余烬开场 4→3，消耗余烬保底 3→2，卡面预览与实际结算共用常量。
- 章节奖励仍有明显价值，但减少高频叠加：主齿轮由每 4 张牌触发，改为每回合第 4 张牌仅一次；大摆锤不再每回合同时回能抽牌；深城总典每回合额外抽牌 3→1，万炉动力核首次消耗返能 2→1。各章即时金币、生命和状态收益也适度回收。
- 分开原本只是换数值的用途：旧书改为打能力牌准备回响；深城时钟改为周期余烬与全体易伤；铜筹码支持删牌，铸币印支持购买成长；古城心石要求第 2 回合实际堆出至少 10 格挡才回血，琥珀泪则在第 3 回合低血时救急。
- 人工复核跨池覆盖：缝血针改清易伤与少量格挡，不再覆盖血滴坠饰的抽牌；暮色镜片延后获得按剩余手牌防御的符文护体；破晓晶石要求首回合节省能量，第二回合兑现；风暴铃需要能力牌铺垫，并只对最低血敌人施加易伤。
- 组合收益仍保留。当前限制主要是每回合次数、周期、条件和数值，不声称所有构筑都没有强组合，也没有给所有治疗增加整场次数上限。

## 重复性检查

`npm run audit:relics` 将结构化规则及旧 ID 规则转为机制签名，忽略名字、数值、计数阈值、稀有度、来源和独立效果顺序，保留触发时机、一次/周期/每次、条件类型和资源类型。v0.1.8 的 15 组机制碰撞降为 0，当前完整描述相同的组数也为 0。新增未适配的旧式 ID 会直接报错，避免漏检。

旧重复家族包括血契护符/密封干粮/坚根结/古城心石/琥珀泪，骨灰坛/炭筛，回响石/旧书，踏灰靴/皮革护腕，烟灰面罩/岗哨灯，磨石/巨人印，墨井/护身墨，朝圣者印章/铁匠围裙，发条日轮/深城时钟，以及获得金币、战后金币治疗、开场敏捷格挡、消耗群体燃烧、获得生命金币、营火生命成长等组。

完整签名不能发现所有“只多一个附加效果”的覆盖，因此另人工检查上述 4 组同角色可获得的跨池问题，并新增实际出牌断言。签名唯一不等于所有用途完全不重叠。

- `npx tsc --noEmit -p tsconfig.app.json`、`npm test`、`npm run build` 全部通过：42 个测试文件、650 项测试。

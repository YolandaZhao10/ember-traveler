# v0.1.18 验收与平衡记录

## 变化与护栏

新增9种普通敌人、15组遭遇，前三章各3种，保留第四章五站单线。单只压力釜、锯轮、隙星枪客限于章内前段，后段使用组合或既有遭遇，避免低压单敌延续到章末。新意图均可提前查看；条件只在选择下一意图时求值。守灯人仅治疗存活目标；净化有间隔；临时力量会归还；禁页看守只在开场塞一次重负；穿透明确标注且仍受力量、虚弱、易伤影响。

问号在实际地图中的比例约由19.89%增加到24.38%，基础抽取故事/战斗/商店权重为70/20/10，有同类型短期冷却。事件历史、节点回退、未来地图隐藏、旧档迁移分别测试。地图仍保证前四层无精英、每完整路线2–5营火、首领前整排营火、前19层至少3节点。

偷钱怪前五回合绝不逃跑，从第六回合开始20%概率预告。攻击和燃烧可在逃跑前追回钱款，逃跑不触发击杀收益；全逃、部分逃、精英逃、刷新和SL均有实际结算测试。

格挡显示展开以容纳9999，所有正常获得途径共用上限；只记录实际增加量，存档及回退点超额格挡修正为9999。

回响/镜像逐次计入出牌、攻击、技能和余音进度，按次触发遗物及敌人激怒。第一攻加伤仅用于真正第一攻，递增攻击加伤读取每次最新计数；不能跨过第三/第四次门槛而漏触发。首次/每回合一次的奖励仍仅一次，能量费用及实体卡去向各一次。已结束战斗不虚增后续次数。本牌新回响不递归复制。

## 界面验收

使用独立sessionStorage测试页面，未改玩家原存档。实际点击验证问号预览隐藏去向、事件/战斗/商店入口、买牌后SL恢复原货架、刷新继续同一商店、逃跑意图及带走金币后返回地图；实际打出回响打击，余音从1/3跨过门槛抽1张，出牌/攻击均累计2次，只花1能量。检查9种新怪造型、朝向、各章背景、多人槽位。9999格挡在1280×720与390×844下不裁切、页面不横向溢出；开发控制台无错误。测试页面打包前删除。

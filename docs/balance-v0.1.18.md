# v0.1.18 验收与平衡记录

## 变化与护栏

新增9种普通敌人、15组遭遇，前三章各3种，保留第四章五站单线。单只压力釜、锯轮、隙星枪客限于章内前段，后段使用组合或既有遭遇，避免低压单敌延续到章末。新意图均可提前查看；条件只在选择下一意图时求值。守灯人仅治疗存活目标；净化有间隔；临时力量会归还；禁页看守只在开场塞一次重负；穿透明确标注且仍受力量、虚弱、易伤影响。

问号在实际地图中的比例约由19.89%增加到24.38%，基础抽取故事/战斗/商店权重为70/20/10，有同类型短期冷却。事件历史、节点回退、未来地图隐藏、旧档迁移分别测试。地图仍保证前四层无精英、每完整路线2–5营火、首领前整排营火、前19层至少3节点。

偷钱怪前五回合绝不逃跑，从第六回合开始20%概率预告。攻击和燃烧可在逃跑前追回钱款，逃跑不触发击杀收益；全逃、部分逃、精英逃、刷新和SL均有实际结算测试。

格挡显示展开以容纳9999，所有正常获得途径共用上限；只记录实际增加量，存档及回退点超额格挡修正为9999。

回响/镜像逐次计入出牌、攻击、技能和余音进度，按次触发遗物及敌人激怒。第一攻加伤仅用于真正第一攻，递增攻击加伤读取每次最新计数；不能跨过第三/第四次门槛而漏触发。首次/每回合一次的奖励仍仅一次，能量费用及实体卡去向各一次。已结束战斗不虚增后续次数。本牌新回响不递归复制。

商店付费删牌基础价格按本局成功次数累计：75→125→175，每次加50，跨章保留；折扣再乘算。无效/取消/金币不足/重复操作不增加计数，营火与事件删牌不计入，SL同时恢复牌组、金币、计数。存档版本升至18；旧档从更新后开始累计，不推算无法可靠还原的历史，已生成商店保留原价。

## 第二、三章与开场压力

第二章大多数敌人基础生命增加约5%，炉窑监工只增加2，炉渣虫保留原生命，避免随从数量放大耐久增幅。第三章多数普通怪生命增加10%–14%，碎镜灵只增加1基础格挡；剑侍、守望者、巨像生命分别增加10、6、6，约4%–9%。部分普通重击与剑侍落月斩增加1基础伤害，保持原控制频率。

坠星司辰基础生命260→290（标准60层681→759），首轮镰斩18→19、双轨9×2→10×2、屏障20→24；转阶段格挡24→28、力量2→3。屏障自身易伤提供下一回合爆发机会；过渡时自身虚弱2层，实际留下1层用于降低转阶段后第一斩，之后恢复完整攻击。帷幕保留非攻击窗口。

四章各有一次性高压开场：决斗者12、锯轮4×3、彗犬16、最终首领24基础伤害，玩家仍先行动且意图完全可见。原终章精英不额外加突袭，以免叠加过密的强制战斗压力。

- 开场与首领独立对照：8场景×8流派×8种子×前后，共1024场；对照454胜、新版457胜，各章各流派损血/胜率护栏通过，无非法状态或停滞。[结果](opening-pressure-v0.1.18.json)
- 二、三章完整覆盖：38种遭遇，80个合法楼层场景，8流派、每行8种子，前后共10240场。相同牌组、遗物、随机序列，仅替换敌人定义。第二章逐场景胜率降幅不超过20个百分点、额外损血比例不超过0.20，第三章上限分别为25个百分点、0.25；另检查逐章逐流派、任何遭遇不能全构筑零胜、第三章首领原有胜场的流派不能变为零胜。最终全部通过，无非法状态或停滞。[逐行结果](chapter-pressure-v0.1.18.json)

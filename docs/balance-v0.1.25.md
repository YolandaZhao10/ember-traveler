# v0.1.25 卡牌与状态牌验证

本版合并此前暂存的计分、税吏逃跑时机、拾灰者燃烧牌、学者回响牌、迷途商贩、旧火重燃与血誓卡牌调整。此前“本地待发布”记录保留作为过程记录，本版起正式提供下载。

## 通用余烬抽牌与加费

- 罕见「炭中寻页」：0费，每消耗2余烬抽1，最多3/4张，消耗。
- 稀有「烬炉鼓风」：0费，每消耗2余烬获得1能量，最多3/4能量，消耗。
- 两张均至少需要2余烬才能打出；只消耗实际兑换的部分，余数和超出上限的部分保留。与固定3余烬换2能量的燃料交换、固定2余烬加1能量费用抽3/4的炭火启示形成启动门槛、单位效率及兑换上限的取舍。
- 回响每次重新检查并支付余烬，余额不足时停止重放；消耗触发长明、导流与火星冠冕一次，回收后也不能重复兑现已花掉的余烬。通用配额更新为22普通、19罕见、17稀有。

## 三种新状态牌

- 灼伤：无法打出；回合末仍在手中时受到2点可格挡的固定伤害，然后自动消耗。不会套用力量、虚弱、易伤，也不算主动卖血。提前弃掉或消耗可避开该伤害。
- 黏液：1费，打出后消耗；不打则照常进入弃牌堆。
- 缠缚：0费，随机弃1张其他手牌，消耗；可以先用掉关键牌再清除，空手时也能清除。

眩晕继续保留，图鉴现在有4种状态牌。它们不能升级，不进奖励、商店和永久牌组，不算诅咒计分。

## 验证与局限

- 类型检查、完整1608项测试（86文件）及生产构建通过。
- 312张卡、613种基础/升级形态，完全同效、仅表面差异、条件下位、能力包含关系检查均未发现冲突。自动审查不能替代所有构筑用途的人工判断。
- 全卡2452组真实结算探针通过；12张改动牌基础/升级、单怪/群怪、各24种子，共1152场精英支持牌组模拟无停滞或非法状态。
- 新状态牌与蓄力恢复前后对照：4角色8路线、9场合法后期遭遇、各8种子，各576场标准难度；胜场526→519，未触发下降15个百分点或额外损血15个百分点的阈值。检查无实体重复、非法状态或停滞。
- 困难最终Boss：2组构筑×8路线×32种子＝512场；旅人0/128、拾灰者0/128、血誓者26/128（20.3125%）、学者0/128。**血誓者高于旧版不超过5%的目标**，主要受取消吸血上限及回血调整影响。本版保留用户指定的无上限与新效果，没有将旧阈值冒充通过。
- 浏览器隔离存档实测拾取/蓄力基础和升级的抽牌、临时力量、余烬及消耗；灼伤可格挡、自动消耗，黏液付费清除，状态图鉴与详情不展示虚假升级版。

固定构筑每场满血，机器人不等于真人或完整旅程胜率。报告见 [原始统计](balance-v0.1.25.json)。前三章资源成本与整局体验仍需试玩反馈。

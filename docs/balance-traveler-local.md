# 旅人专属牌调整（本地未发布）

本轮只在分支 `claude/shared-card-pool-redesign-1f8287` 上提交，未合并、未重新打包。基线为 `a231827`（共享卡池改版之后）。数值均为初稿。

目标：连击牌在 3 点能量下更容易启动，关键牌战鼓更早拿到；壁垒只加输出，不动叠甲机制。铁壁、架盾、漫长守望、节奏、回身刺、环刃本轮没有改动。

## 规则与存档

- 没有修改引擎。引擎里每次回响或镜像重放都算一次出牌，所以条件降到 1 之后，本回合第一张攻击牌被重放时，重放那次已满足条件；这与连环斩原有的行为一致。
- 战鼓降为罕见后不再出现在首领奖励里（首领奖励只出专属稀有牌），改从普通、精英奖励和商店的罕见位出现。
- 引灯连斩是不消耗的 0 费过牌牌，触发「可重复零费牌预算」护栏。经确认登记为实付 2 点余烬的已审核例外，与烬中翻阅同类；护栏规则本身未改。
- 不息步伐通过既有的 `RETIRED_CARDS` 处理，不升存档版本。牌组、战斗中的各牌堆、待领奖励、商店货架和回退点都会替换，不消耗随机流。

### 构筑审计（120 种子）

| 路线 | 场景 | 胜场 | 平均回合 | 平均损血比例 |
|---|---|---|---|---|
| 连击 | 第一章单体 | 120 → 120 | 2.1 → 2.1 | 4.3% → 4.2% |
| 连击 | 第一章群体 | 120 → 120 | 3.2 → 3.2 | 5.5% → 5.5% |
| 连击 | 第三章首领 | 118 → 119 | 5.7 → 5.8 | 29.0% → 27.5% |
| 连击 | 最终首领 | 89 → 90 | 7.6 → 7.8 | 57.9% → 63.1% |
| 壁垒 | 第一章单体 | 120 → 120 | 3.2 → 2.9 | 0.7% → 0.7% |
| 壁垒 | 第一章群体 | 120 → 120 | 5.0 → 4.3 | 1.7% → 1.2% |
| 壁垒 | 第三章首领 | 120 → 118 | 19.8 → 14.2 | 38.5% → 41.9% |
| 壁垒 | 最终首领 | 90 → 86 | 30.4 → 21.6 | 65.4% → 70.0% |

没有停滞或非法状态。

- **壁垒变快但少赢了几场。** 第三章首领少赢 2 场、最终首领少赢 4 场，损血比例升高 3 到 5 个百分点。带 `--before` 配对时脚本给壁垒打出 −0.241（阈值 −0.05），这个配对护栏没有通过；结果与事先预估一致，按预期内接受。推测原因是碎盾倍率升到 3 后机器人更常用它清空格挡，未逐场验证。
- **连击最终首领损血变多。** 胜场 89 → 90，但损血 57.9% → 63.1%；成型牌组里受影响的只有疾刺和千刃，千刃升级版条件格挡 24 → 16 是最可能的原因。
- **引灯连斩在成型连击牌组里很强。** 把牌组里的绊倒换成引灯连斩：第三章首领 120/120、5.0 回合、损血 21.1%；最终首领 108/120（90%）、6.9 回合、损血 49.4%。

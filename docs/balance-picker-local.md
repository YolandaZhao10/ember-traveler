# 拾灰者焚烧牌本地复核

本轮仅本地保存，未上传或重新打包。基线为 `bcf4345`，已包含上轮浓烟3/4层燃烧。此次人工复核拾灰者30张焚烧流派牌及其基础/升级形态；费用、资源、铺火、群攻、控制与续航一起判断，不能把持续燃烧仅当成首回合伤害。

## 最终调整

| 卡牌 | 基础版 | 升级版 | 用途与边界 |
|---|---|---|---|
| 拨炭 | 燃烧3→4 | 燃烧4→5 | 保留1费、抽1，补强循环铺火；不增加能量或抽牌量 |
| 灼灰横扫 | 群体燃烧1→2 | 群体燃烧1→2 | 保留4/6点群体攻击；即时伤害与燎原的高层持续燃烧仍有差别 |
| 隔火带 | 燃烧2→3 | 燃烧3→4 | 补强低燃烧时的防护；倍率仍2、格挡上限仍18/24 |
| 添油 | 增加消耗 | 仍然消耗 | 按用户追加要求；翻倍、格挡倍率和上限保持；回响结算两次但实体仅消耗一次 |

灼痕曾试过追加伤害6/8和6/7，两轮24种子成熟构筑均少赢一场第三章首领，未通过既有配对护栏；最终保留原4/5，不以单卡数值增加代替整套收益。

## 其余卡牌判断

| 卡牌 | 保留原因 |
|---|---|
| 点燃、燎原、余火 | 初始铺火、纯群体持续伤害、铺火兼即时格挡已有清楚分工和足够收益 |
| 灼痕 | 需要铺火的双段即时输出；试改未通过构筑对照，恢复原值 |
| 引爆、热浪、炭火长枪 | 分别消耗燃烧爆发、保留燃烧群攻、按燃烧强化单体攻击；成型后已可成长 |
| 火钳勾击、燃点、炉口吐息 | 分别提供条件抽牌、易伤窗口和条件格挡，不额外提高所有铺火输出 |
| 烬舌、炭刺、借火鼓风 | 0费工具，保留消耗/低数值/真实支付燃烧的约束 |
| 烟屏、裹炭、烟幕护身 | 分别负责燃烧防护、余烬支撑、消耗控场；不改成同一张防御牌 |
| 浓烟 | 上轮刚提高到3/4层，保留群体虚弱与随机消耗的取舍 |
| 炉灰余温、不灭之火 | 持续点火与停止衰减已有复合收益；不把持续能力一起上调 |
| 火葬、火线蔓延、送葬火炬、窒息余火 | 稀有牌分别承担死亡传播、铺火传播、消耗爆发后续火、群体控制；保留现值 |
| 白热、不息炉膛、拾薪归炉 | 资源兑换、余烬联动、实体回收已有构筑价值，不增加资源循环上限 |

## 验证

- 1516项测试（80文件）、TypeScript检查、生产构建通过。新增基础/升级添油的回响、格挡、消耗一次和下一轮不洗回验证；更新隔火带低燃烧收益断言，高层格挡上限断言保留。
- 303张牌、598种形态的效果/描述、近似设计、能力覆盖和条件收益覆盖检查通过；没有新增完全相同或普通升级覆盖稀有基础的已知模式。自动检查不等于证明不存在任何近似体验。
- 三张加强牌各以24个相同种子比较基础/升级、单体/群体、普通/精英，前后共1152场。全部无非法或停滞，候选均实际出牌；逐场景胜场不下降、平均额外损血≤1、平均回合延长≤0.25。普通测试难度较低，均获胜，不据此宣称真人胜率。
- 精英场景平均损血（基础/升级、单/群体等权）：拨炭25.96→24.95，灼灰横扫26.84→26.37，隔火带6.20→5.73。普通场景部分组合会因机器人选牌改变多损约0.1生命，未掩盖为全指标改善。
- 完整焚烧构筑4场景×24种子×前后共192场对照通过，两侧都使用添油消耗以隔离三张小加强的影响。早期单体平均2.083→2.042回合，其他场景胜场不变；无非法或停滞。
- 添油消耗确实明显降低持续翻倍收益：相同标准成熟配方，第三章首领21/24→11/24，最终首领5/24→0/24。这里按用户要求保留消耗，没有同步削弱首领或偷偷上调其他卡补回。
- 困难最终首领：沿用固定旧配方和循环配方、焚烧/灰烬两路线，种子320–447共512场，2/512（0.39%），均来自灰烬循环配方；两组焚烧样本均0/128。仍低于之前要求的5%上限，但这是复用种子的固定机器人诊断，不是独立验证或真人通关率，也不能说明焚烧终局已均衡。
- 浏览器独立sessionStorage验证基础与升级卡面、群体铺火、隔火带先施加燃烧再起甲、拨炭抽牌；实际玩家存档未用于测试。

# v0.1.16 全卡逐项审查

覆盖282张定义：275张可打出牌的基础/升级版，加7张不可升级诅咒，共557个形态。保留每池20普通、18罕见、15稀有；调整38张（普通1、罕见10、稀有27），其余保留。

审查以费用、手牌代价、生命/余烬代价、一次使用或持续循环、启动回合、条件与成型收益共同判断。稀有牌应有值得构筑的优势，但不要求在任意资源状态下都比升级普通牌更好。力量多段、保留蓄力、燃烧传播等收益不能只按裸伤比较；能力牌打出后移除，不当作可循环技能。

所有卡牌通过四种资源情景的实际引擎结算。下表描述从最终数据生成，包含费用与升级形态；对照结果、失败试改及限制见[平衡记录](balance-v0.1.16.md)。

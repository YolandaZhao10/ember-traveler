# v0.1.22 验收记录

本次包含构筑循环卡、卡牌离手反馈、快捷键，以及地图和商店交互调整。主存档版本仍为18；地图笔迹独立格式升至2，可读取旧笔迹，断点随笔迹保存。

## 新卡与联动

| 角色 | 新牌 | 构筑用途 |
| --- | --- | --- |
| 旅人 | 回锋整备、换岗布防 | 攻击回手继续连击，技能置顶配合下回合蓄能；可接战途补给与卸甲疾行 |
| 拾灰者 | 灰中分拣、拾薪归炉 | 抽牌堆随机三选一送弃牌并补牌；回收弃牌中尚未使用的消耗牌，群体燃烧衔接借火鼓风 |
| 血誓者 | 血线牵引、伤痕固守 | 失血回收攻击/技能，触发血甲和失血抽牌；保留当前手牌，跨回合组织力量、回血与回脉忆战 |
| 灰语学者 | 星页检索、叠页演算 | 随机候选中检索并获得回响；弃牌置顶并给手牌蓄力，可接释能演算 |
| 通用 | 余烬拾遗 | 稀有1费、升级0费，选择消耗区一张牌回手，自身消耗 |

角色新牌均为罕见。总卡池302张（含7张诅咒）：229张专属奖励、56张通用奖励、10张初始。

选择只移动已有实体，不生成复制牌，也不免费打出。随机候选在打开/取消时不消耗随机流，确认后才推进；不允许绕过候选或用错牌堆的UID。回响只重复其他效果和出牌计数，不重复移动同一张牌。血誓重演不能选择含牌堆选牌效果的牌，避免嵌套选择。

余烬拾遗不能选择任何带消耗区回收效果的牌，包括条件中的回收效果，因此不能两张互捞或捞另一种回收牌。正常治疗牌可以取回，重新打出仍支付原费用、原代价并遵守消耗。血线牵引为0费消耗；其他可重复回收和置顶牌需要1能量。当前手牌保留只作用于这一回合，之后新抽入的牌不自动保留。

## 其他调整

- 地图橡皮擦擦掉触及的局部线段，保留两端与其他笔迹；缩放后的预览保持相同屏幕擦除宽度。刷新恢复断点，不把两端重新连起来。
- 通关或失败的结算页及菜单提供“结束旅程”，保留既有胜负、用时与最终牌组；不计作放弃。结束后清除本局存档和回退点。
- 新商店第一排依次为攻击、攻击、技能、技能、能力；第二排前两格通用，其余随机。10张不重复，角色过滤、稀有度权重、价格区间及折扣保留。能力位无对应稀有度时优先交换整店已抽出的稀有度位置；仅极端全部普通且卡池没有普通能力时为能力位重抽可用档位。旧存档货架原样保留。
- Space打出所选牌，单体牌先指向敌人；Esc取消；牌堆选牌窗口Enter确认；R快速SL。R在战斗、奖励等局内界面共用现有回退点，编辑输入框、组合键、按住重复和忙碌结算时不触发。
- 消耗与效果弃牌产生包含原牌UID、升级与蓄力快照的离手事件，显示具体卡牌和“随机消耗/随机弃置”标签。消耗燃烧淡出，弃置滑向弃牌堆；每批最多4张，连续批次错开。普通出牌弃置与回合末整手弃牌不刷提示。快动画每张保留700毫秒；系统减少动态效果时使用纯淡出。动画不决定规则结果，结算先保存，刷新不会重复结算。

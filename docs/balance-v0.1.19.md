# v0.1.19 血誓重演验收记录

## 改动

- 割脉刃基础/升级均消耗，伤害和吸血不变。猩红收割原本已消耗，加入基础/升级实际结算测试确保保持。
- 新增血誓者罕见技能血誓重演：2费，升级1费，自身消耗。选择弃牌中的攻击/技能免费重放，原牌不移动；其他资源代价照付。不接受能力、诅咒或重放选择器。
- 弃牌与目标都在确认前选择，取消不扣资源；确认后完整结算并保存。选定卡牌版本被固定，抽牌洗回原牌不产生复制。回响再次执行来源时仍使用同一选择，每次重新检查目标与余烬；不转移已死目标，不递归触发重放中的回响/镜像。
- 来源技能、被选攻击/技能分别计数，复用既有出牌/攻击/技能触发。回血牌、出牌计数、余音、遗物、激怒、资源不足、非法选择、洗牌、回响、存档序列化与SL均有回归测试。
- 总计283张卡，血誓者罕见牌由18增至19，其他配额不变。选择窗口是临时UI，未改变存档结构，存档版本仍为18。

## 验证结果

TypeScript检查、65个文件共1253项测试、生产构建通过。全卡相似性扫描覆盖559个基础/升级形态，完全同效、奖励效果相同、仅修改表面参数三项均为零。[全卡记录](card-similarity-v0.1.19.json)

机器人新增公开弃牌及目标选择分支，实际执行新牌；没有替它提供牌堆顺序等隐藏信息。以下对照采用同种子、同支持牌、同策略，12种子×单怪/群怪/精英×基础/升级×三个版本，共216场。[原始结果](blood-replay-v0.1.19.json)

| 版本 | 胜场 | 平均结束生命 | 平均回合数 | 血誓重演实际出牌次数 |
| --- | ---: | ---: | ---: | ---: |
| 修改前（割脉刃可循环） | 72/72 | 72.62 | 4.72 | 0 |

全部场景无停滞、非法状态或实体牌重复。基础精英战改为消耗后的平均结束生命67.50→46.50，说明可循环吸血削弱明显；加入重演后49.42，并将回合数8.83降至7.58。升级精英战重演组结束生命反而由74.25降至72.33，体现用防御牌位换爆发的取舍。本次未继续改动治疗数值或新牌费用。

固定支持牌组全部获胜，不能据此推断整局或真人胜率，也没有声称所有构筑都已平衡。现有200局启发式整局测试同样执行，报告不代表真人强度。本次对照重点是确认削弱有效、新牌实际可用，以及没有免费递归循环。

## 界面验收

使用独立sessionStorage，不修改玩家真实存档。实测：选牌→取消保持3能量与原手牌；选择巨人连击时多个敌人必须另选目标，确认后只有指定的第二个敌人200→172，能量3→1、重演进入消耗区、原牌仍在弃牌堆。刷新后保持该结果。改选防御无需指定敌人，实际获得5格挡。能力、诅咒及另一张重演均不出现在可选列表。

1280×720桌面窗口可完整看到卡牌、目标与确认按钮；390×844视口页面宽度仍为390，确认按钮在视口内。开发控制台无错误。测试页不进入构建和试玩包。

复跑：`npm run audit:blood-replay`、`npm run audit:card-similarity`、`npm test`。

# 余烬旅人（Ember Traveler）

一款以《杀戮尖塔》为类型参考的原创单人 Roguelike 卡牌构筑游戏。穿过「灰烬古城」「熔炉深城」与「星骸天穹」，最后抵达「余火终庭」挑战无昼之主。前三章各 20 层，终章为 5 站单线，共 65 层。四名可选角色（旅人、拾灰者、血誓者、灰语学者），中文界面，本地运行，以电脑浏览器和键鼠操作为主要游玩方式，保留触屏适配。

技术栈：React 18 + TypeScript + Vite，无其他运行时依赖。美术支持位图贴图，缺失时回退到内联 SVG 与 CSS，音效由 WebAudio 合成。

## 启动

```bash
cd ember-traveler
npm install
npm run dev        # 开发服务器，默认 http://localhost:5173
```

```bash
npm run build      # 生产构建到 dist/（可直接静态托管）
npm run preview    # 预览生产构建
npm test           # 引擎单元测试 + 无头整局模拟 + 数值粗评
```

给朋友试玩：运行 `npm run package:play`，将生成的 `release/EmberTraveler-play.zip` 发给对方即可（打包电脑需有 `zip` 命令，macOS 自带）。对方安装 [Node.js LTS](https://nodejs.org/en/download)，完整解压后双击 Windows 的 `play-windows.bat` 或 macOS 的 `play-macos.command`，自动在浏览器打开游戏；无需安装项目依赖、配置密钥，安装好 Node.js 后可离线玩。启动器只监听本机 `127.0.0.1:5199`，此地址不能发给别人远程访问。存档由每个玩家自己的浏览器保存，试玩包不携带测试进度。

## 操作

- **开局难度**：「开始旅程」旁提供轻松、标准、挑战、自定义四个入口。自定义使用 50%–200%、步长 1% 的滑块，分别调整怪物生命、金币掉落、遗物稀有度倾向、卡牌稀有度倾向、怪物攻击意图、Boss 攻击意图和 Boss 生命。生命、伤害/格挡、金币按百分比乘算，其中敌人生命与意图继续叠加楼层强化，基础金币不随层数增长；意图出招顺序、状态效果和阶段切换不变。稀有度百分比表示倾向强度而非实际掉落概率：50%/100%/200% 时普通、罕见、稀有权重分别乘以 1.5/1/0.5、1/1/1、0.5/1/1.75，中间连续插值后归一化。角色过滤、指定稀有奖励不变，首领卡牌始终稀有。轻松预设生命 75%、意图 80%、金币 150%、稀有度倾向 200%；标准均为 100%；挑战生命 130%、意图 125%，其余 100%。本局开始后固定，跨章、刷新和 SL 均保留。
- **桌面端**：将攻击牌拖向敌人，指向线和目标高亮确认目标后松手出牌；也可点击选牌，再点击敌人。无需目标的牌拖到战场即可使用，或再次点击该牌 / 点「打出」。拖到无效位置松手、点击战场空白、右键或 Esc 可取消瞄准；未瞄准时右键卡牌查看详情（含升级版本）。
- **手机端**：点击卡牌，再点击敌人；无需目标的牌提供「打出 / 详情 / 取消」浮条。手牌区可横向滑动，长按卡牌查看详情。
- 点击敌人头顶的意图或敌人本身可查看它的招式说明；点击状态标签查看解释；点击余烬数字查看规则。
- 顶部栏：地图、牌组浏览、战斗记录、音效开关、菜单。菜单统一收纳快速 SL、卡牌图鉴、遗物图鉴、旅程记录、怎么玩、快速动画和返回标题等操作。首页四角色横排，常见电脑窗口无需滚动。战场左上角保留最近 3 条战斗记录，可展开完整记录。
- **旅程记录**：标题和局内菜单都可打开，按角色统计通关、倒下、放弃和胜率，可按角色/难度/结果筛选。胜率为通关 ÷（通关 + 倒下），进行中与放弃单列而不计入分母。每次结算保存种子、难度、楼层、生命、完整牌组（含升级与重复张数）及遗物。每个新旅程有独立记录标识，同种子重开另计，同一局 SL 后更新原条目而不重复计数。记录存于独立 localStorage 项，不随清除当前存档丢失；从此版本开始收集，无法补录已经删除的旧局。
- **地图与预览**：路线图在宽屏上限制放大幅度并居中，缩短层间距；1366×768 电脑窗口主地图约可同屏查看 10 层，右上角地图预览约 8 层。当前位置自动定位到视野偏下方，优先展示前方路线；窗口尺寸改变时重新定位，仍可滚动查看整章。终章五站完整同屏。右上角「地图」可随时查看路线与当前位置；预览不能移动，关闭后继续当前操作。
- **选路与构筑（v0.1.14）**：战斗节点在开章时固定敌组，同层在可选池足够时优先安排不同遭遇、尽量避免相邻战斗重复。地图点选展示收获类别与后路，确认后才移动；普通和精英入场前不显示阵容，首领可提前查看。高亮所选分支，显示最近营火/商店距离及到本章首领的精英场数范围，包含所选节点，不推荐所谓最优路线。Tab 进入地图节点，方向键比较，回车查看，再 Tab 到确认按钮；右上角预览始终只读。
- **快速 SL**：菜单内回退当前阶段。战斗中回到本场开局；战胜后改为奖励回退点，撤销领奖、重新选牌，保留战后生命和击杀统计，不用再打一次小怪。营火可撤销休息或敲牌；商店、事件可重做本节点操作。离开节点回到地图后仍可回退，进入下一节点后更新回退点。牌组、金币、遗物与随机状态一起恢复，相同操作得到相同结果，奖励内容不重掷。行动动画期间按钮暂时禁用。
- **卡牌图鉴**：标题页和局内的右上角菜单均可打开。查看全部 282 张卡牌，按角色、流派、类型、稀有度筛选，搜索牌名或效果，切换升级版并点击卡牌对比。角色页默认只看专属牌，可开启「包含通用牌」。每个角色恰好有普通 20、罕见 18、稀有 15 张专属牌；通用牌同样为 20/18/15，初始牌和诅咒另计。图鉴使用规则层自动生成的说明，不受当前战斗增益影响。
- **遗物图鉴**：菜单内查看全部 208 件遗物：常规可获得遗物普通/罕见/稀有各 45 件，共 135 件；额外四角色各 3 件严格专属遗物（每档 1 件），共 12 件；每章 9 件章节遗物，共 36 件；另有 15 件问号事件专属、6 件商店专属，4 件初始遗物另计。列表独立滚动，支持滚轮、触屏及键盘翻页。独立分类为普通、罕见、稀有、问号专属、商店专属、章节专属与初始遗物；三档常规分类各含 45 件常规与 4 件角色专属，共 49 件。稀有页不会混入问号、商店或章节奖励；全部页也按这七类分组。支持角色、仅角色专属、章节筛选和名称/效果搜索。章节遗物只来自对应首领三选一，不混入商店或普通遗物掉落池。
- **键盘提示**：战斗手牌上方显示对应的 1–9/0 键帽，随手牌位置更新；抽牌堆旁常驻显示选牌、点击敌人/打出和 Esc 取消提示，结束回合按钮内显示 E。数字键只选牌，再按同一数字取消；选中后点击目标，无需目标时点击「打出」。E 结束回合；Enter 未聚焦其他按钮时也可结束回合，聚焦按钮时执行该按钮。Esc 取消选中 / 关闭弹层。手机和触屏隐藏键盘提示，保留点选与长按操作。满手十张牌会适度重叠，结束回合按钮保持在屏幕内。
- 标题页可输入种子；同一种子的地图、奖励、洗牌、事件结果完全一致。
- 「继续旅程」会显示存档楼层，下方显示角色、生命与种子；「新的旅程」从第 1 层开始，确认后替换旧存档。

## 规则速览

- 每回合 3 点能量、抽 5 张牌，手牌上限 10。抽牌堆不足时自动把弃牌堆洗入。
- 敌人在你行动前显示下一步意图（攻击伤害 × 次数 / 防御 / 强化 / 削弱 / 特殊），显示数值已包含力量、虚弱、易伤修正。
- 结算顺序：回合开始（清格挡 → 燃烧 → 遗物/能力 → 能量 → 抽牌）→ 出牌 → 回合结束（能力结算 → 状态递减 → 弃手牌）→ 敌人依次行动（清自身格挡 → 燃烧 → 招式 → 状态递减 → 选择下一意图）→ 死亡检查贯穿每次伤害。
- **格挡**：玩家与敌人统一上限 9999，护盾标记随数字宽度展开，完整显示四位数；超额部分不计入实际获得量或浮字。旧档与回退点的超额格挡归至上限。
- **余烬**：内部范围为 0–9999；界面只显示当前数量，不展示上限或容量格。战斗内跨回合保留，战斗结束清空。「引火」「添薪」「火炬」等牌积累，「余烬爆发」「烈焰吐息」「灰烬护盾」消耗全部余烬按点数结算，「灰烬之刃」「余烬疗愈」需要并消耗固定余烬。
- **四名角色**（标题页选择，余烬卡池共享）：
  - **旅人**（生命 72，「余烬灯」：战斗开始 +2 余烬）：连击 / 壁垒 / 余烬。
  - **拾灰者**（生命 66，「拾灰者的铃」：战斗开始所有敌人 2 层燃烧）：焚烧 / 灰烬 / 余烬。
  - **血誓者**（生命 80，「血誓印」：战斗开始失去 2 生命、获得 1 力量）：血誓 / 狂力 / 余烬。
  - **灰语学者**（生命 52，「回响石」：战斗开始获得 1 层回响）：回响 / 专注 / 余烬。新局采用 52 点生命上限，已有存档保留当前上限与成长。
- 旅人的三条可组合构筑方向：
  - **连击**：疾刺、双刃、连环斩、回旋踢、节奏、急速、千刃、余音、战鼓、绊倒；遗物燧石、节拍怀表、鼓手之心。
  - **壁垒**：举盾、盾击、荆棘甲、铁壁、反击、固守、钢铁意志、碎盾、守望、盾墙反震；遗物锈蚀胸甲、荆棘冠、砧铁碎片。
  - **余烬**（四名角色共享）：添薪、余烬爆发、烈焰吐息、灰烬护盾、火种之心、燃烧、灼热打击、余火之舞、焰柱、火炬、熔炉、灰烬之刃、疾风余烬、余烬疗愈；遗物炭心、灰烬沙漏、余火香炉。
- 拾灰者的专属路线：
  - **焚烧**：点燃、燎原、灼痕、引爆（移除燃烧按层数伤害）、添油（燃烧翻倍）、余火、热浪、烬舌、火葬（每回合全体 +燃烧）、不灭之火（燃烧不衰减）；遗物火绒盒（燃烧伤害 +2）。
  - **灰烬**：拾取、焚书（消耗换能量）、骨灰、尘归尘、灰烬盛宴（消耗时得格挡）、火种传递（消耗时随机伤害）、焚尽（消耗全部手牌按张数伤害）、灰烬再临（从消耗区取回）、献灰；遗物骨灰坛（每回合首次消耗抽牌）、余烬镣铐（有消耗则回合结束 +2 余烬）。
  - 燃烧规则：敌人在自己行动开始时受到等于层数的伤害（无视格挡），然后层数 -1。
- 血誓者的专属路线：
  - **血誓**：血刃、血祭（失去 3 生命：抽 2、+1 能量）、吸血撕咬、血契（失血得力量）、殉道、痛觉麻痹、猩红护甲（失血得格挡）、饮血（敌人死亡回血）、以血还血；遗物铁颅、血瓶。
  - **狂力**：蓄力（临时力量，回合结束失去）、怒吼、碎骨、力量碾压（伤害 + 力量 × 2）、狂暴、恶魔之心、重锤、震慑、血怒；遗物战号。
- 灰语学者的专属路线：
  - **回响**：回响 / 双重咏唱（下一张非能力牌触发两次）、回声刃、共鸣（每回合得回响）、镜像（每回合首张攻击触发两次）、灰语、咏叹、符文爆发、终章（手牌越多越痛）；遗物旧书、音叉（回响触发得余烬）。
  - **专注**：符文护盾 / 符文壁 / 蓄势之刃（**保留**：回合结束留在手牌，每保留一回合蓄力增强）、专注（下回合 +1 能量）、冥想、博学（每回合多抽）、守护符文、灰烬方程（余烬翻倍）、预读；遗物透镜（偶数回合开始时有保留牌则 +1 能量）。
- **能力叠加**：数值型能力按总量累加；余音、镜像和焰柱按每张独立结算。余音生效后每打出 3 张牌抽 1 张，升级抽 2 张，进度跨回合保留、不计自身，回响与镜像每次重放分别计入出牌、攻击或技能次数，逐次触发余音、连击与相关遗物；能量只支付一次，实体卡只弃置或消耗一次，状态栏显示每张的 `0/3` 进度。镜像各自重放每回合生效后的首次攻击，可与回响叠加；焰柱每张分别使用当前余烬计算伤害。固守/不灭之火属于开关规则，重复拥有不改变同一规则。
- **卡牌差异**：基础版和升级版一起检查完整规则与实际说明；同一角色可获得的奖励牌另做近似设计检查，数值、费用、段数、单体/群体及保留/消耗不能单独作为不同牌的特色。量步即时抽牌；提灯巡守给予 6/9 格挡，本回合已经打出至少 2 张牌时为下回合储存 1 能量。荆棘甲提供即时格挡与荆棘；刺盾姿态先加 1/2 荆棘，再将自身荆棘翻倍，抽 1 张并消耗。盾击保留格挡、攻击单体；碎盾固定 2 费，先消耗全部格挡，再按格挡值 2/3 倍群攻，回响不能重复使用已消耗的格挡。检查也覆盖卡牌目标入口，避免无需选敌的牌混入无法生效的单体效果。
- **差异化复核（v0.1.4）**：重新设计 20 张定位重叠的牌。灰烬步改为有格挡时获得余烬；连环斩/追风步为后续攻击提供有门槛的临时力量；不息步伐在三次攻击后准备回响；漫长守望改为持续抽牌与格挡。藏炭消耗手牌换余烬；火线蔓延传播目标燃烧；隔火带按目标燃烧获得有上限的格挡；白热消耗燃烧换余烬与抽牌；灰烬再临优先回收最高费牌；尘归尘只清理诅咒。重锤先破盾再伤害；岿然清理虚弱、易伤、脆弱和燃烧，但不会清除临时力量的归还标记；最后献礼失血后整手换牌。破碎符文与未来记忆提供即时蓄力，符文壁改为一次蓄力防御加持续金属化。停战烟侧重群体虚弱与换牌；重拨余火花余烬回收；篝火避难所建立持续防御。卡牌数量和角色稀有度配额不变。
- **防止重复设计回归**：无依赖的效果换序不再算作新设计，例如“抽牌后加能量”和“加能量后抽牌”；仍保留先加力量再攻击、先抽牌再蓄力、资源支付与条件判断等真实顺序差异。规范化缺省参数，交叉检查基础/升级、通用/专属卡池及特色初始牌。自动审查用于拦截已知重复模式，不代替构筑用途的人工复核。
- **终夜焚天**：2 费，消耗所有余烬，每点对全体造成 4 点伤害并施加 1 层虚弱；升级为 5 点伤害、2 层虚弱，不再给格挡。0 余烬时仍能施加虚弱。
- **偷窃与追回**：掠夺者、灰烬税吏偷窃时立即扣除实际金币，最多偷走当前余额；每只敌人独立累计保管。击败它时立即全额返还，包括攻击、群攻、燃烧、荆棘和遗物击杀，顶部金币与战斗记录同步更新；敌人详情显示它持有的金币。返还不是战利品，不受金币掉落难度或遗物加成影响。刷新和 SL 保留/恢复对应钱包与偷窃记录，不能重复领取。旧版进行中的战斗迁移为实际扣款，已死敌人的账目取消；已经结束并结算的旧战斗无法追溯补发。
- 通用机制：攻击带「荆棘」的敌人会被反伤；部分敌人死亡时有触发（余烬虫死亡点燃你）。

第三章「星骸天穹」使用 10 张新怪物透明贴图和 7 张新背景，以月白石、暗紫夜幕与旧金星仪为主题；终章「余火终庭」使用 2 张新敌人和 6 张新背景，以黑曜石、苍白石灰与窄线晨光为主题。两批均已逐张检查透明通道和朝向；设计提示词位于 `scripts/chapter-three-art.txt`、`scripts/chapter-four-art.txt`，脚本清单由 `scripts/later-chapter-art.mjs` 读取。

战斗中玩家朝右、敌人朝左，放大的形象会根据窗口高度与敌人数适配。多个敌人各占独立槽位，死亡后暂时保留空位，避免点击目标突然重排。战斗背景使用低饱和冷色远景与轻微景深，人物保留暖色和轮廓光，并使用同一地面站位。

攻击包含前摇、挥击弧光、目标斩击、命中闪光、短促震动和合成音效；完全格挡显示蓝色护盾。特效根据真实结算事件定位，群攻覆盖实际受击者，连击分次显示，燃烧与荆棘使用独立反馈。普通与快速动画的前冲时长分别为 480ms 与 216ms；结算结果在前摇开始时保存，刷新不会重复执行攻击。系统启用减少动态效果时关闭前冲与镜头震动。

需要重新生成时，可为脚本配置图片生成接口。设置 `IMAGE_API_URL`（完整接口地址）、`IMAGE_MODEL`（模型标识）、`IMAGE_API_KEY`（密钥）后运行：

```bash
node scripts/gen-art.mjs
```

配置可写入环境变量或项目根目录的 `.env.local`（已被 git 忽略）；不要提交密钥。接口须接收 `model`、`prompt`、`size` 等 JSON 参数，并返回 `data[0].b64_json` 图片数据。脚本涵盖全部 85 张图，输出到 `public/art/` 并写入 `manifest.json`；游戏启动时读取清单，有图用图、缺图回退 SVG。支持 `--only characters,enemies,backgrounds,archetypes,chapter2_enemies,chapter2_backgrounds,chapter3_enemies,chapter3_backgrounds,chapter4_enemies,chapter4_backgrounds`、`--force`、`--dry`、`--quality low|medium|high`。例如 `--only chapter2_enemies,chapter2_backgrounds --dry` 只检查第二章的 17 张素材清单。

也可自行制作素材，按脚本中的素材 ID 命名后放入 `public/art/`（支持 webp / png / jpg / jpeg）。角色与敌人须保留真正的透明通道。仅更新已有素材清单无需 API 密钥：

```bash
node scripts/gen-art.mjs --manifest-only
```

## 代码结构

```
src/engine/   纯 TypeScript 规则层，不依赖 React
  rng.ts      带种子的随机数（mulberry32），按用途分流
  types.ts    数据结构
  cards.ts    卡牌视图、伤害 / 格挡公式、描述生成
  combat.ts   战斗状态机：出牌、回合、敌人行动、死亡与阶段
  map.ts      地图生成与校验
  run.ts      局内流程：节点、奖励、商店、营火、事件、结算
  save.ts     localStorage 存档与版本迁移
  history.ts  独立旅程记录、胜率与牌组快照
  powers.ts   逐张能力实例及旧状态兼容
src/data/     结构化内容：characters / cards / enemies / relics / events / statuses
  extraRelics.ts 常规扩展与角色专属遗物规则
  chapterRelics.ts 前三章各9件首领奖励及终章旧纪念遗物
  specialRelics.ts 15件问号专属与6件商店专属遗物
  extraEvents.ts 新增17个章节事件，含15件问号遗物对应故事
  relicRules.ts 遗物描述自动生成
  extraCards.ts 新增143张角色专属牌，按角色与稀有度分组
  sharedCards.ts 新增39张通用牌，补齐53张共享奖励牌池
  curses.ts    新增6种诅咒，回合末效果与描述使用同一份数据
src/ui/       React 界面：store（状态 + 动画调度）、screens、components、sprites
src/test/     vitest：引擎单测、无头整局模拟（30 种子）、启发式机器人数值粗评
```

新增卡牌/敌人优先在 `src/data` 中添加定义。原遗物由 `combat.ts` / `run.ts` 按 id 触发；扩展遗物通过 `extraRelics.ts`、`chapterRelics.ts` 的结构化规则注册，`relicRules.ts` 从同一规则生成说明。战斗与旅途分派器统一结算，新增规则类型时须同步描述和真实触发测试。

## 已知限制

- 数值经过规则测试与启发式机器人验证；65层旅程、扩展卡池与逐层强化改变了构筑和生存压力，胜率不能直接与旧版比较。机器人不会规划抽牌引擎、保留蓄力与余烬爆发时机；达到单场400次行动上限的局单列为停滞，不计作通关或死亡，最终难度仍需根据真人试玩反馈调整。
- 现有四章，提供预设和自定义难度，尚无成就系统。后续章节保留角色基础卡池，分别配置独立敌人、背景和章节遗物；第三章有独立事件，终章为固定五站。
- 未生成贴图时，美术为程序化 SVG 轮廓与符号；音效为合成音。
- 卡牌「灰烬」等战斗内塞入的诅咒只存在于该场战斗；事件带来的诅咒会进入牌组。
